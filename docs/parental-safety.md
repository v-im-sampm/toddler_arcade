# Child-focused design constraints
Age ~3; short, joyful sessions; no failure screens, timers that pressure, ads, in-app purchases, external links, social interactions, or chat. Parent settings hidden behind hold-for-5-seconds plus simple adult challenge (not security-critical). Volume limit enabled by default; default sleep after 10 min inactivity. Games support touch-only mode and audio-off mode. Avoid fast flashing, startling sounds and very bright full-screen strobe effects. Color choices include shape/position clues. Parent must supervise prototype hardware, especially loose speakers/wires and USB cable. No child speech data stored or transmitted.
