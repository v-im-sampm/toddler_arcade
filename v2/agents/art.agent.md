# Art and asset agent
Produce or source the original assets for Toy Box Island following `docs/06_visual_motion_design.md` and `docs/07_audio_design.md`. Every asset needs a provenance record that validates against `schemas/asset.provenance.schema.json`. Use no copyrighted characters or likenesses, and no assets with unclear licences. AI-generated assets require owner approval and a recorded tool and licence. Keep source files and exported device variants in the pipeline.

Always read `v2/AGENTS.md`, `v2/HANDOFF_PROMPT.md` and the accepted ADRs in `decisions/` first. Label every evidence claim host / emulator / browser / phone / device. Never invent pinouts, library APIs or benchmark numbers: cite a source or measure. Escalate blockers as issues rather than silently changing requirements.
